# Microsoft Store Demo Submission Checklist

## Package

- [ ] MSIX generated by `Package-WindowsMsix.ps1`
- [ ] version matches `CMakeLists.txt`
- [ ] package identity matches Partner Center
- [ ] publisher matches Partner Center
- [ ] package is signed according to the selected Store workflow
- [ ] artifact SHA256 recorded
- [ ] artifact JSON record saved

## Functional Smoke Test

- [ ] install on clean Windows 11 machine
- [ ] launch from Start menu
- [ ] regulatory splash is visible
- [ ] main window opens
- [ ] DICOM folder import works
- [ ] main viewer displays selected slice
- [ ] MPR opens only within documented limitations
- [ ] 3D viewer opens only within documented limitations
- [ ] XA cine opens only within documented limitations
- [ ] app closes without crash

## Store Listing Claim Control

- [ ] listing says education/research/controlled evaluation only
- [ ] no diagnostic-use claim
- [ ] no treatment-use claim
- [ ] no clinical decision-support claim
- [ ] no certified/approved claim
- [ ] no completed PACS/archive/worklist claim
- [ ] no cyber-proof or hospital-ready cybersecurity claim

## Privacy And Data

- [ ] privacy policy available
- [ ] DICOM files may contain health/patient data
- [ ] local data storage behavior is disclosed
- [ ] no cloud upload is claimed or performed by default
- [ ] database/log/audit location is documented

## Current CAPA / Known Limitations

- [ ] CAPA-001 malformed/corrupted DICOM handling limitation disclosed or closed
- [ ] CAPA-002 measurement/MPR clinical-correctness limitation disclosed or closed
- [ ] release record states non-diagnostic demo status

## Validation

- [ ] Windows App Certification Kit executed
- [ ] failures fixed or recorded
- [ ] install/uninstall verified
- [ ] dependency DLLs verified on clean machine
- [ ] representative CT/MR/XA import tested
